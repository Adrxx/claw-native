Captain Claw recovery map

What has been recovered from the original game, what has recorded app-trace evidence, and what is still missing. The complete game is not playable yet. The Mac app opens on the original main menu, shows the original loading screen after New Game, and runs Level 1 at 60 fps through recovered code; finishing Level 1 cleanly and moving to Level 2 is the work in progress.

The cast of every level

The 14 level files place tens of thousands of objects. Each object names the class of code that runs it: a rat, a crumbling peg, a boss. Having code for every class is necessary but does not establish that a level is playable. The bars show the share of each level's placed objects by the state of their class.
