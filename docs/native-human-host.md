# Native Human/Officer/Soldier/Bullet host components

`ClawNativeHumanoid.swift` and `ClawNativeBullet.swift` supply independent native components for the frozen original HumanEnemy, HumanCombat, EnemyMotionAux, CommonEnemyEntries, OfficerLogic, SoldierLogic and ordinary BulletLogic bodies. They use the existing scene token heap, recovered scene actor creation, mutable original state registry, raw ANI/image resource binders, actual collision map, shared player RNG and native audio. This is host integration of recovered behavior, not additional binary recovery or whole-game completion.

## Component interface

Create `try ClawNativeHumanoid(kind: .officer/.soldier, snapshot: actor, scene: scene, resources: resources)` after WWD load/adoption. `tick()` runs the registered controller. `callback(_:argument:)` invokes an original method identity; `refresh()`, `flush()` and `snapshot()` synchronize the raw actor/logic/private views. Public `state`, `generic`, `officer`, `human`, `combat`, `motion` and `soldier` pointers expose the original view contexts for narrowly scoped services. Diagnostics are `failure` and the `unresolved` set; a nil failure does not imply all external services have implementations.

Private heap storage is exactly Officer/Human 284 words, Soldier 288 words, ordinary Bullet 84 words. Officer points the Human private-tail view directly into its 20-word context tail; Soldier supplies a separate 24-word tail. Flush and reload concatenate/split these original spans, preserving the frozen common ABI. Stable recovered class vtable spans are installed in the same scene heap for destruction dispatch. Existing common construction and secondary LogicHit/contact LogicAttack binding bodies execute; no constructor, idle, melee or physics behavior is copied into Swift.

`ClawNativeHumanoidGlobals` is shared across every humanoid in one scene. `globals` or component aliases expose difficulty, scale factors, countdown, strong-throw and strike-counter fields. Pinned executable static values are difficulty537964=0, countdown541334=0, strongThrow537224=0 and strike52713c=1. Scale factors default to the explicit existing host profile1. Root may synchronize these with its actual configuration and gameplay globals. Strike-counter changes are committed at native boundaries; the shared scene object supplies the RNG and audio services. Production refresh uses `scene.gameTime` and `scene.animationDelta`. Optional `frameClock` is an explicit injected frame input for direct component testing; it creates no timer or fixed-step scheduler.

State metadata comes from `ClawEnemyStateView`. Human/common/Officer views use their original raw tables separately. Soldier's actual class table53c328 is resolved locally over the same bootstrap registry because the shared convenience map currently lacks its name; no shared file edit or invented state IDs is needed. Nonempty name tokens remain the allocated CString tokens from registry bootstrap, never replaced with literal-token identities.

## Bullet creation and dispatch

`onBulletCreated` publishes a new `ClawNativeBullet` for root attachment, while `bullets` retains the humanoid's child components. It fires after actual scene creation and before the source's subsequent resource/startup calls. Creation invokes recovered `claw_scene_actor_create` with public `scene.entry(named:"Bullet")` metadata and all original creator values, including flags40000. Supplying the resolved entry avoids dependence on root's private literal-name dictionary; it is equivalent to the named wrapper's resolved-entry call for this verified metadata. The source body still controls image selection, callback ordering, damage10/type40, velocity±500, zero Y velocity/gravity and negative rectangle mirroring. It does not use a fabricated projectile allocation or launch controller.

`ClawNativeBullet(snapshot:scene:resources:)` has `tick`, `callback`, `refresh`, `flush`, `snapshot`, diagnostics and the same optional service/frame hooks. Its raw image selection, first-frame geometry, startup and FALLING controller are frozen BulletLogic. `electedPlayerHit()` uses the existing shared player's frozen CaptainClawHit handler only after the scene interaction host elects that callback for this Bullet; it synchronizes the full attacker actor and player snapshot. Existing root interaction routing already calls that same player handler and can continue to do so, then refresh the component on its next callback. No separate immunity, contact election, TTL or deletion timing is invented.

Root must attach dictionaries/callback routing for registered actor functions Officer462350, Soldier48a980 and Bullet40fec0. Shared LogicHit4dc830 and LogicAttack4dc850 must route by actor token to the matching component. The existing plain gameplay dictionary is insufficient for private deleting destructor calls because their receiver is the private token and argument0 is flags, not an actor token. Route Officer462a00, Soldier48afd0 and Bullet484d90 by `generic.enemyToken`, forwarding flags unchanged. On outer actor teardown remove root component entries. Humanoid refresh prunes child entries whose actor heap span no longer exists; deinit releases remaining child references. Preserve the scene/frame's existing stable-freed-storage scope across native actor/list destruction.

Root owns WWD population selection, spatial record registration, shared bridge/project/build lists, ordinary frame/interaction execution and devices. Add these two Swift files and EnemyMotionAux/CommonEnemyEntries/SoldierLogic/BulletLogic C++ modules and headers to its build. This worker edited none of those shared files.

## Exact services and explicit gaps

The adapter handles allocation/free, named state resolution, logic/image binding, sequence/sound lookup, ANI selection/update, native collision/ground/horizontal/point queries, shared RNG, audio playback and the recovered bitset/CString destruction leaves through the existing scene actor host. Resource misses follow the recovered zero/fallback paths. ANI calls flush live stores before executing the original raw animation body and reload its writes.

The inlined ledge probe in EnemyMotionAux requires immutable cell/row/description pointers; `ClawHumanoidTiles` loads the same LEVEL1 WWD, pins exact native spans and weakly caches one view per root while components retain it. Dynamic movement, ground placement and the other ledge probes use the existing shared collision map and scene actor candidates. The cached view has no invented platform actors; the original inlined probe reads tiles only.

Unimplemented calls are offered to `externalService(ClawGenericEnemyCall) -> UInt64?`, preserving original function, receiver, all supplied arguments and name. Before a supplied service the current raw snapshots are flushed; a handled service reloads its actor/private writes. Returning nil retains the address in `unresolved`. Loot42df90, particle461a00, speech420370/48ce40/48ceb0, effect actor creation/resources, and unrecovered multiargument common helpers43ee10/43eee0 remain explicit services. Other-actor resource/ANI/collision calls are offered to this service rather than applying them to the receiver component. Root can compose its Goodie/WorldLoot/effect/speech host implementations here and provide effect pointer views in the exposed Human context; this module does not claim those graphs are implemented.
