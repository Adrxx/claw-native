# Original ordinary Bullet logic

`BulletLogic.h/.cpp` recovers registered callback `0x40fec0`, constructor `0x4107c0`, shared projectile constructor `0x473c50`, class dispatch `0x473f40`, initialization `0x4741f0`, FALLING entry/update `0x474290/0x4742f0`, deleting destructor `0x484d90` and base destructor `0x456030`. It composes frozen GenericEnemy scheduling/motion/post and PlayerDamage. The bounded image setter `0x4c7970` is also recovered for GAME_BULLETS and LEVEL_MUSKETBALL, so the Soldier launch chain can execute its actual resource selection before Bullet initialization.

The source is the fingerprinted original v1.0 executable, SHA256 `350b8d51e1cd52037cd31a7722197a815e4206e7d3052ec632465f1354726263`. Actual whole `0x401000` registration records Bullet literal `0x522e0c`, callback `0x40fec0`, flags zero. Registered CBullet class array `0x538428` installs LS_FALLING→`0x4742f0` through original `0x474060`. The test retains actual whole-bootstrap CString heap tokens and all raw class/name arrays. Nonempty name tokens are heap copies, distinct from the original name literals.

## Storage and C API

The original wrapper allocates exactly **0x150 bytes, 336 bytes, 84 words**. `ClawBullet` aliases frozen `ClawGenericEnemy` snapshot storage, but only private words 0–83 belong to the Bullet allocation. Every compatibility-padding word is preserved. The common frozen layer's larger-object bitset guard is temporarily adapted during common calls and restored before each external dependency and at return; it never writes a corresponding word in the original allocation. Actor and primary views remain 128 and 93 words.

`ClawBulletContext` points to a caller-owned GenericEnemy context, actual projectile class-state views, and optional `ClawSceneActorHost`. Without `scene.lookup`, it provides explicit image registry/root/header/frame-array/leaf views. Raw image roots need 27 readable words; the compatibility header has 28 words and preserves its extra word. Leaf geometry needs ten words. Frame array origin/count are explicit and signed frame IDs remain signed. With lookup, the resource manager and frame pointer are read from actual scene/root spans. The existing host token and buffer identities must match actor `+0x6c`, primary `+0x18`, and private wrapper fields; normal constructed aliases are not arbitrary string aliases.

Initialize frozen GenericEnemy context defaults and supply its globals/default constants, state views and exact token identities; `claw_bullet_context_defaults` installs the twelve verified Bullet virtual methods:

`484d90, 4c9e30, 473f40, 4063b0, 4741f0, 4bb030, 4bb030, 4c96b0, 4c96b0, 4dca10, 474290, 4bb030`.

`construct` executes the actual constructor; `tick` executes the registered actor callback. `entry` supports the listed routines, common `4dc870/4dca10/4063b0`, and the verified empty virtual entries. Its support return is separate from the recovered result output. Incidental EAX from original void methods is not a claimed behavior. Unknown entries/image names are unsupported. Check `context.fault`: 1 means a missing service or raw view; 2 means failed startup allocation. No success is inferred after a diagnostic.

## Startup and physics

State 0 writes primary state 1000 before requesting the allocation. It constructs, invokes virtual `+0x10`, then commits the resulting private token to primary `+0x18`. State 29 invokes virtual `+0x20`, state 30 invokes `+0x1c`, state 1000 does nothing, and all other states enter actual common scheduler `0x4dc870`. Normal registered callback return is 1. Allocation failure has no normal original return: it dereferences zero at `0x40ff1e`; the portable API reports fault 2 after preserving the verified pre-fault mutation and allocator event.

Shared construction installs actor/logic wrappers and exact LogicHit/LogicAttack binding calls, initializes the frozen physics layout, and preserves every untouched allocation word. Bounds initially come from signed primary `2c/30/34/38` values when nonzero, otherwise the original default doubles. Actor coordinates/initial velocity use signed DWORD interpretation. The clock at `0x473d6e` is explicitly loaded as an **unsigned** zero-extended DWORD converted to double and multiplied by the original 0.001 constant. The CRT's original precision-53 semantics are used by the instruction oracle and portable arithmetic.

It performs common motion with actor mode 7, then establishes actor/logic wrappers `128/12c/130`, sets actor flags `+8 |= 0x60` and `+164 |= 0x2000`, clears ANI root `+148`, and resets all three axis bounds to the original defaults. Bullet construction changes vtable to `0x50b714` and zeros gravity. When actor image root `+170` is zero it resolves GAME_BULLETS and selects its first frame. An existing image root leaves the existing frame/leaf unchanged. A missing resource stores root zero and preserves the old frame/leaf.

Initialization reads the current leaf's half-width/half-height/offsets into movement and attack rectangles, if a leaf exists, and invokes virtual `+0x28`. FALLING entry saves the previous state, resolves LS_FALLING, conditionally saves/selects the private ANI root, and sets actor mode 8. The registered class dispatcher reads the actual class callback; a known zero slot makes the original error service `0x4a36f0` explicit.

## Flight, contact and destruction

FALLING update advances ANI only when private `+148` is nonzero. It checks the **previous frame's** collision mask `+120 & 0x10000` and sets actor Delete flag `+8 |= 0x10000`. Common post subsequently performs current physics/collision. This ordering causes the measured one-frame collision-to-Delete delay. No TTL, invented fixed frame rate or forced offscreen expiry exists in these recovered ordinary bodies.

Soldier FIRING creation composes frozen `0x48ba00` with the whole native Bullet startup and image setter. The creator arguments remain container, ID 0, original X/Y offsets, depth minus one, literal Bullet, flags `0x40000`. LEVEL_MUSKETBALL is selected and damage 10/type `0x40` are written before the actual callback. Only after startup does Soldier set signed X velocity ±500, Y velocity zero and gravity zero, then mirror the appropriate rectangles. Original-disc MUSKETBALL FRAME001 has width 12, height 11 and zero offsets; positive flight rectangles are `(-6,-5,5,4)` and negative mirroring follows Soldier's verified asymmetric arithmetic.

The Bullet vtable's hit/attack slots are empty `0x4bb030`. `0x474290` is the FALLING entry, **not** a hit handler. The scene interaction election chooses actual CaptainClawHit `0x41ce80`, which handles ordinary type `0x40`, applies the original damage/death behavior and marks the Bullet Delete unless its explicit alternate destruction flag is set. `claw_bullet_player_hit` composes the frozen PlayerDamage body after the caller binds player actor `+74` to the actual Bullet token. Damage context attacker storage is canonical at each dependency; the adapter synchronizes the full Bullet actor before and after every dependency and at return. The Bullet private/primary buffers remain intact. This helper does not elect contact or bypass scene collision scheduling.

Private deleting destruction sets base vtable `0x50b014`, frees the captured receiver iff the supplied flags' low bit is set, and returns that captured receiver. The base destructor makes that same vtable store. No additional ordinary private resource cleanup is invented. The outer scene actor/list/interaction teardown remains frozen ActorDestruction/SceneActorRuntime host composition; this module supplies their class-specific private destructor entry.

## Verification and external boundaries

Run `work/test-env/bin/python Tests/compare_bullet_logic.py`. The verified result is **2,339 whole Bullet/Soldier calls**, **3,591 ordered complete callback snapshots**, **3,510 executed original instruction addresses**, plus **368 whole composed CaptainClawHit calls** with **3,276 ordered player/damage/input/global snapshots** and **457 hit-body addresses**. The allocator failure adds one independently checked pre-fault prefix/event. Strict C11 header and C++17 warning-as-error compilation pass. Ghidra logs contain no SCRIPT ERROR. Evidence, disassembly and a detailed retained-history report are in `work/bullet-agent/`.

The basic matrix compares eleven whole bodies with 100 seeded complete states each and five wrapper branches with 24 states each: image absence/presence/missing lookup, clock boundaries including unsigned high/wrap values, private ANI absence/presence, collision masks, state identities, free flags, default-bound profiles and live resource/ANI mutations. Final buffers include complete actor/primary/secondary/contact/private compatibility snapshots, player/attacker/platform/effect views, private Human tail and backing, raw globals, image headers/frame arrays, actual registry arrays and the retained 1 MiB CString heap. External events carry exact receiver/name/semantic arguments in order and the entire represented state at that point; stack-local resource out-parameter addresses are normalized by the frozen service ABI.

All sixteen actual Level1 Soldier WWD records execute frozen original/native initialization and firing entry, then whole original/native Soldier→image setter→Bullet startup. Each retains flight for up to 80 frames on actual Level1 collision geometry, stopping on Delete; five naturally collide/delete within that finite window, and eleven remain in flight. The private destructor is compared separately for every history and is explicitly host-invoked for still-live fixtures. Two solid-wall fixtures compare actual original/native collision and verify both the first collision without Delete and the next frame with Delete, followed by destruction. The original collision instructions and frozen TileCollision/CollisionResponse execute rather than a fabricated mask. Player-hit comparisons feed the actually created Bullet actors across five health thresholds/four movement modes, then retain three-contact hurt/death histories for all sixteen records; these explicitly elect the hit handler.

Allocator, generic named actor creation, WWD resource lookup, CString/binding services, ANI/resource leaves, sound/effects, error reporting and OS interfaces remain declared service boundaries. The retained creator adapter supplies stable raw actor/primary/private spans, zero generic primary bounds and ordinary actor value/interaction flags before startup; it is not a claim of whole scene creation/heap allocation parity. The actual Soldier/Bullet bodies, resource setter, common motion, tile geometry and PlayerDamage bodies execute across that boundary. The tests do not implement DirectSound, native rendering, full broadphase/interaction election or whole scene removal, and cannot establish whole-game behavioral identity.

CMagicBullet is separately registered at literal `0x5241a4` with class array `0x534ab0` and extended callbacks `0x410a80/0x410b90/0x410d60`. Its update reads private `+150/+154`, outside ordinary Bullet's allocation. Its sparkle/effect behavior is deliberately outside this ordinary Bullet module; it must not be enabled by extending the ordinary 84-word prefix or substituting those callbacks.
