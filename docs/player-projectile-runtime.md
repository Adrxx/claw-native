# Original player weapon projectiles

`PlayerProjectileRuntime.h/.cpp` recovers the original registered PistolBullet `40ff80`, MagicBullet `410040`, and Dynamite `43a850` graph. Sources are the fingerprinted original v1.0 `CLAW.EXE`, SHA256 `350b8d51e1cd52037cd31a7722197a815e4206e7d3052ec632465f1354726263`, and original disc `CLAW.REZ`, SHA256 `b09802735970de6ee6115259a15af384d09abaed9e80b4107f9e69b7573f4596`.

## API and original ownership

The C11 API uses raw 32-bit tokens and `ClawSceneActorHost`, a borrowed frozen `ClawBulletContext`, six exact global words, and a rich dependency with function/receiver/12 argument words/name. `entry` returns native completion/support separately from original EAX. Incidental EAX from source void methods remains outside parity claims; `486e70` also exposes its verified computed candidate. Unknown entries are not implemented. Fault 1 reports missing spans/services, fault 2 an observed unsafe prefix, and fault 3 a bounded iteration/domain rejection. These safe exits are not substituted original normal returns.

## Behavior and integration recipe

PlayerAttackInput `41c5a0` already owns ANI marker election, ammo, launch positions and pre-initialization actor writes. Keep that updater in the host and route its named creator to actual source actor creation. Its `40000` flag creates a deferred actor: the updater writes launch fields before the next registered projectile callback. Do not initialize the private projectile inside the creator before those writes.

Pistol uses GAME_BULLETS and the shared Bullet class. Source launch damage8/type20, signed horizontal velocity±700, Y velocity0 and primary+b8 repeat identity come from the frozen updater. Ordinary FALLING checks the previous collision mask, so collision-to-Delete occurs on the following update. No recovered pistol TTL is added.

Magic uses GAME_MAGICCLAW, GAME_CYCLE50, source damage25/type2000000 and velocity±700. It sets actor flag80000. Private+150 is the sparkle count and +154 an optional Flare actor, not Bullet compatibility padding. If `53724c==0` and actual owner+124 is nonzero, construction creates Flare and sets sparkle count2; otherwise Flare0/count1. FALLING advances the ordinary Bullet body, creates GlitterBaby actors with the exact signed remainder/random ordering and current rectangle/physics fields, calls their actual primary callbacks immediately, then positions the Flare at truncated current physics coordinates. The loop re-reads its count after each callback. State29 `414010` marks the retained Flare Delete. The underlying hit/attack virtual slots remain original empty `4bb030`; do not install a fabricated player or target hit callback.

Dynamite uses image GAME_DYNAMITELIT. Its ANI lookups are GAME_DYNAMITELIT, GAME_DYNAMITEHORZ and GAME_DYNAMITEEXPLO, with sound GAME_KEGBOOM. **DYNAMITEHORZ is ANI-only; there is no corresponding GAME image group in the actual disc.** Construction sets attack rectangle(-50,-50,50,50), movement/hit geometry from the selected image, gravity2000, collision options8, bounce limit2 and fuse1250. The source inline retarget calculation composes the frozen exact physics helper, including signed-zero behavior, then subtracts the absolute wrapped doubled actor+158 launch-distance value from vertical velocity. Frozen PlayerAttackInput owns the signed/clamped charge-to-distance conversion.

Bounce initialization `408870` selects lit ANI, sets mode8/flag2, enters FALLING, performs the actual clamped tile foot query, then records fuse duration and absolute tick. RawTileDescriptionRuntime composes the elected type1/2/3 virtual point getter. A solid foot invokes virtual3c; Dynamite `43b1e0` stops physics and changes depth2134. Update `4089d0` advances ANI first, checks unsigned tick subtraction against the fuse, then handles grounded bounce. It invokes virtual34, optional bounce sound, checks equality with the bounce limit, and otherwise adjusts Y by-1, corrects vertical velocity with source gravity arithmetic, writes deltaY=-1 and scales X/Y velocity by+0.5/-0.5. Dynamite's virtual30/34/38/3c methods are `43b160/43b120/43b1a0/43b1e0`.

Fuse virtual38 stops physics, optionally plays explosion audio, and calls virtual2c `43b210`. That entry selects explosion image, enters EXPLODING, changes attack type1000000, selects explosion ANI and clears its first-marker latch. `43b290` suppresses attack with flag80 each update; the first marker1 sets its latch, extends the source shake deadline by500 and clears flag80 for that interaction pass. Later updates do not fabricate another damage window. Completed ANI marks the actor Delete. The outer scene handles deferred deletion and state29/state30 cleanup.

The shared deleting destructor `484d90` writes base vtable50b014 **before** requesting physical free, frees iff flags&1, and returns the captured private token. This raw adapter preserves the exact free-event snapshot. It does not invent additional resource releases.

## Explosion deadline

Complete `486e70(duration)` has no dependencies. It computes `candidate=raw541328+duration` with DWORD wrapping, then stores raw53c260 iff the existing value is unsigned<=candidate. Its observed EAX is candidate even if the older deadline wins. It consumes the **outer real clock**, not stage tick or animation delta.

Raw53c260 is frozen SceneCameraRuntime `shakeUntil`. The already recovered Camera486240 tail compares it unsigned against animation-now5430c8 and invokes its recovered486a00 shaking path. Hosts must alias raw53c260 to the camera global and keep clock541328 synchronized with the actual five-word ClawClockState. No extra random offsets, guessed shake duration or independent timer is added here. Keg callers can route486e70 through this API with a minimal context; a Bullet adapter is unnecessary for that entry.
