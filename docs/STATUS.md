Evidence levels:

- **none**: No comparison against the original exists.
- **provisional**: A comparison exists; nobody independent has checked it.

- **source-only**: Not compiled into the app.
- **compiled**: Compiled into the app; host election is not recorded.
- **elected**: Wired from a Swift host; recorded original-call-graph app trace pending.
- **live**: Reached through the original call graph in a recorded app trace.

The manifests list 3235 original functions as owned by modules with comparison evidence, 713,150 bytes. The function index holds 4,643 functions of 16 bytes or more; those below the C runtime and library code (address under 0x4a0000) total 611,906 bytes. That puts the recovered share of game code near 117%. Ownership lists for legacy families are incomplete, so treat this as a lower bound on comparison-backed declared ownership.
