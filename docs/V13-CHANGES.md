# Captain Claw v1.3 gameplay overlay plan

This inventory is incomplete. The REZ comparison, registered-logic map and discovery-gap ownership are complete; function matching, the full game/platform partition and exhaustive effect classification are not. The semantic checker enumerates outstanding reviews instead of accepting candidate counts as closure. No gameplay implementation or shared harness was changed.

Local source-effect review distinguishes changed and unmatched bodies from unchanged local bodies; the task also requires an independent checked game/platform partition. `normalized-body-review.json` excludes 943 pairs whose complete bytes agree after checked address normalization. It preserves opcode bytes, scalar constants, registers, instruction sizes, field offsets, virtual slots and local branch destinations. An unchanged local body does not discharge an unresolved partition. Another 80 byte-shaped matches remain open because an immediate value lacks sufficient address evidence; being inside the image range alone is not a relocation proof. Unchanged local bodies can still call changed helpers or reference changed data, so their bindings remain explicit.
