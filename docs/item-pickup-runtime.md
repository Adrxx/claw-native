# Original ordinary item pickups

`ItemPickupRuntime.h/.cpp` recovers the whole registered callbacks TreasurePowerup `0x46fd10`, its coin/glitterless alias `0x470100`, HealthPowerup `0x470d00`, MagicPowerup `0x470f00`, and AmmoPowerup `0x471100`. It also recovers the whole pickup sound helper `0x41d6f0`, treasure counters `0x41f850`, collected-treasure marker `0x473ae0`, auxiliary-scene predicate `0x405f80`, and only the dynamite ID `0x26b0` branch of `0x41ee60`. It composes the frozen whole CaptainClawHit `0x41ce80` implementation for the supported ordinary award categories. The original executable SHA256 is `350b8d51e1cd52037cd31a7722197a815e4206e7d3052ec632465f1354726263`.

## Host API and state

`claw_item_pickup_entry` accepts the actual function token, thiscall receiver where applicable, and original stack arguments. Support is returned separately from original EAX. The no-argument thiscall predicate `0x405f80` accepts a null argument pointer with count zero. Void routines and the alias wrapper have no claimed original return value. Unknown functions or unsupported special awards return zero without claiming success.

`ClawItemPickupContext` contains a token-addressed `ClawSceneActorHost`, the frozen raw loot table, the player's portable locomotion view and actor/primary/private tokens, and explicit original globals. The raw scene spans must contain actor, primary logic, resource roots/leaves, scene/plane, glitter actor, player and auxiliary manager buffers. The player actor occupies 128 words and the award-relevant private view 78 words. `managerToken` supplies original `0x5371fc`, including startup glitter setting `+0x124`. Animation delta, stage delta, unsigned tick, global audio gate/volume, dedup cache `0x534ec0/0x534ec4`, and auxiliary globals `0x534874/0x5349dc` are separate live context fields. Missing storage/services set diagnostic fault 1; an unsupported dependency encountered during composed player award sets fault 2.

`claw_item_pickup_award` supports treasure type `0x40000`, regular health `0x10000` with signed value at most 100, pistol ammunition `0x800000`, magic ammunition `0x100000`, simple health category `0x200000`, and type `0x100` only for dynamite ID `0x26b0`. It requires the player's actor `+0x74` to identify the item. It commits and reloads actor/private/item views at every dependency boundary so mutations remain visible in original order. Contact election, hit gates and frame scheduling belong to the original actor-interaction host; this API does not insert an immunity or proximity rule.

## Startup and lifecycle ordering

State 0 clears primary sound `+0x168`, establishes depth 1000/actor flag `0x20000` when depth is zero, chooses ANI if actor `+0x190` is zero, assigns interaction flags/types and image-leaf rectangles, binds loot metadata, optionally creates PowerupGlitter, then stores state 5. Treasure and magic establish depth before ANI; health and ammo establish it after ANI. Ammo sets actor flag `0x80000` after rectangle work; the other classes set it before. These differences survive callbacks that mutate the live actor and global setting.

Treasure captures the old image root before resolving GAME_TREASURE_COINS. Matching root identity selects GAME_CYCLE100; other treasure selects GAME_POWERUP. Other ordinary classes select GAME_POWERUP. Treasure alone expands the attack rectangle left 6, top 10, right 6, bottom 2. Ammo captures its old image before resolving GAME_DYNAMITE; matching root identity changes its interaction type from pistol ammo to `0x100`.

Metadata binding lazily invokes `0x4719e0` when the loot flag is zero and searches image-root identities in table order. It sets actor ID (index 0 maps to ID 33), value and primary sound; mask replacement occurs only for an actor whose live type is 1. No match sets ID 0/value 100/sound zero. The table has 341 contiguous words, including the ten-word gap before logic metadata; image/value/mask/logic/sound/flag offsets are 0/66/132/208/274/340. The original initialized count is 62 within capacity 66. Counts beyond capacity are a host diagnostic boundary.

Glitter creation uses scene container, ID 1, item X/Y, depth plus one, literal PowerupGlitter `0x522950`, and flags `0x40000`. Treasure suppresses it when the live primary callback is `0x470100`. State 29 marks the glitter actor for deletion; treasure clears its saved glitter pointer, while health/magic/ammo retain theirs.

State 5 advances animation first. Only treasure then observes collected bit `0x200` and changes to state 9000. Treasure state 9000 sets flags `0x21`, removes glitter, reads the scene plane's camera center `+0x84/+0x88`, stores a 400 ms timer and integer velocities toward center minus `(300,280)`, enters 9001 and invokes points-icon effect `0x4737c0`. Arithmetic is unsigned 32-bit wrapping, including multiplication and division. State 9001 saturates the timer by stage delta, sets deletion `0x10000` at zero, moves each axis using the wrapped product divided by 1000, and advances animation afterward. Animation delta and stage delta remain distinct.

## Awards and audio

Treasure adds item value to player score `+0xf8` with wrapping arithmetic, performs sound/counter helpers and marks the treasure collected. The marker returns 1, so CaptainClawHit retains the actor for its 400 ms visual lifecycle. Counter ID categories are 33→0, 1→1, 2–5→2, 41–44→3, 7–10→4, 11–14→5, 15–18→6, 45–48→7 and 49–52→8. Both private arrays `+0x88` and `+0xb0` increment for the selected category; other IDs leave them untouched.

Regular health awards only when signed current health is below 100, then adds the item value with wrapping arithmetic and caps a signed result above 100. Full health leaves the ordinary item unconsumed. Category `0x200000` applies its addition regardless of the starting value. Pistol/magic ammunition update private words 28/29, use wrapping addition and cap a signed result above 99, then play sound and mark deletion. These signed caps are preserved even for negative or wrapped inputs.

Sound helper `0x41d6f0` compares the current unsigned tick and sound-root token against its cache. A different pair updates both cache globals before testing the audio gate or zero root. Enabled nonzero roots call `0x4b45f0` with pool `root+0x10`, master volume and three zero arguments. Disabled audio still changes the cache.

The supported `0x41ee60` dynamite branch uses signed positive item `+0x108`, otherwise amount 5. It updates private `+0x78`, applies the signed 99 cap, invokes sound, marks the item for deletion and conditionally clears auxiliary manager `+0x4c8`. The condition is the whole original `0x405f80` predicate: global auxiliary manager is nonzero and receiver scene `+0xc` equals global auxiliary scene. Other branches of `0x41ee60`, catnip duration/effect helper `0x41f990`, powerups, curses, special pickups and end-level awards remain unsupported.

## Actual loot records and verification

The source-derived, hash-pinned initializer profile in `Tests/world_loot_initializer_profile.json` supplies 46 records whose callbacks are in this module: treasure IDs 0–18, 33, 41–52; ammo 19–21 and 34; health 22–27 and 61; magic 28–30. Startup and ordinary lifecycle are checked for all 46. Awards are checked for 44, excluding catnip IDs 22/23 whose values invoke the unrecovered special-effect helper. The four trailing slots 62–65 are outside the original initialized count.

Binding searches resource identity rather than the declared drop ID. In the compared resource profile, IDs 24 and 61 share LEVEL_HEALTH and therefore both bind the first matching row 24/value 5. Coin IDs 0/33 likewise share the first root and bind actor ID 33. The native code preserves this first-match behavior rather than forcing the later row's value.

`Tests/compare_item_pickup_runtime.py` compares **4,852 whole original calls**, **3,357 ordered complete raw snapshot events**, and **2,255 original instruction addresses**. Every comparison includes all 512 KiB of the token-addressed heap, all 341 loot words, count and explicit live globals. Events preserve ordered numeric function/receiver/argument identities and the same complete snapshots. Directed and seeded cases cover phase branches, null/present leaves, depth and glitter outcomes, repeated sound-cache pairs, unsigned delta/product wrap, signed award/cap boundaries, helper receiver and zero-argument ABI, and callbacks that mutate live actor/global state.

Forty-four retained chains execute whole original BouncingGoodie startup, five grounded bounce updates, actual WorldLoot rebind `0x473660`, the selected ordinary startup and CaptainClawHit award. The native side composes the frozen corresponding implementations. Drop-style launch/gravity/loot-ID writes are explicit between startup and updates. The fixture provides copied CString state-name storage and fixed original registered IDs; the frozen BouncingGoodie suite independently verifies full original `0x401000` registration. This joint fixture does not claim to execute that whole registry bootstrap or the full physical world/scheduler.

Resource lookup, ANI selection/advance, scene creation, audio playback, lazy table initialization, collision and the points-icon effect remain explicit adapters. In joint chains, the original callback/rebind/player-hit/helper instructions execute rather than being replaced by these adapters. The resource identity profile contains source-derived names and shared lookup roots, but does not establish all resource loader implementations. Optional production `composeCreation` uses frozen SceneActorRuntime and still requires its host services; the pickup comparison uses an ordered creation adapter.

Final evidence is `work/item-pickup-agent/test.log`; recovery logs `ghidra.log`, `award-ghidra.log` and `magic-ghidra.log` are free of script errors. The production-only library compiles with `-Wall -Wextra -Werror -ffp-contract=off`. No renderer, native playback, devices, project files or whole-game parity are part of this handoff.
